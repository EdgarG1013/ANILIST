### Pasos de Instalación

**1. Clonar o descargar el proyecto**

```bash
git clone:https://github.com/EdgarG1013/ANILIST.git
```

```bash
cd ANILIST
```

**2. Instalar dependencias**

```bash
pnpm install
```

**3. Ejecutar el proyecto**

```bash
pnpm run dev
```
